Admin sign-in

Use the admin password set in slideshowpi.conf. It is separate from the Wi-Fi password.

Connection

When changing Wi-Fi mode, this page may disconnect. Join the new network, then use the IP address shown in the top-left corner of the TV.

Hotspot

Changing an active hotspot disconnects connected phones. A new name or password also requires a new printed Wi-Fi QR code.

Connect to existing Wi-Fi

The Zero W uses 2.4 GHz Wi-Fi. Joining this network turns off the hotspot. If joining fails, the hotspot returns automatically. Guest networks may block phones from reaching the Pi.

System diagnostics

Updates every 5 seconds. CPU use is measured between samples.

Restart device

The slideshow and Wi-Fi connection will stop briefly. Wait for the device to start again before reconnecting.
